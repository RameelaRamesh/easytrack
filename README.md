# EasyTrack

EasyTrack is a Medical Billing Workforce & Operations Management Platform. It is built as a multi-tenant, role-based SaaS application.

## Project Structure

- `frontend/`: React + TypeScript + Tailwind UI
- `backend/`: Django + Django REST Framework + PostgreSQL
- `docs/`: Architecture, workflows, and API documentation
- `scripts/`: Setup, seed, and development scripts
- `docker/`: Deployment and container configurations
